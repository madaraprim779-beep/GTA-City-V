# GTA City IV - Chapitre 4 : L'Empire (Missions 76 à 100)

## Mission 76 - Le nouveau pouvoir

Objectif :
- Développer son influence dans les trois villes
- Renforcer son organisation

Récompense :
- Nouvelle propriété
- Plus de réputation


## Mission 77 - Le grand investissement

Objectif :
- Acheter une entreprise importante
- Développer ses revenus

Récompense :
- Revenus réguliers
- Nouveaux contacts


## Mission 78 - Le véhicule légendaire

Objectif :
- Trouver une supercar cachée dans un ancien hangar

Récompense :
- Véhicule rare


## Mission 79 - L'accord secret

Objectif :
- Négocier avec un nouveau partenaire

Récompense :
- Accès à une nouvelle zone


## Mission 80 - La grande course

Objectif :
- Participer à une compétition entre les meilleures voitures de la ville

Récompense :
- Voiture de sport exclusive


## Missions 81 à 90

Le joueur :
- Agrandit son empire
- Achète des villas
- Développe ses entreprises
- Découvre de nouveaux secrets
- Affronte les derniers groupes rivaux


## Missions 91 à 100

Le joueur :
- Prépare l'affrontement final
- Découvre la vérité sur Victor Kane
- Rassemble ses alliés
- Se prépare pour la dernière partie de l'histoire


## Fin du chapitre 4

Récompenses :
- Empire développé
- Plusieurs propriétés
- Collection de véhicules rares
- Accès au dernier chapitre

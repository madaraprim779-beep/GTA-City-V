# GTA City IV - Système des Animaux

# 🐾 Animaux Domestiques

Les villes possèdent des animaux qui vivent naturellement.

## Chiens

Comportements :
- Se promènent avec leurs propriétaires
- Jouent dans les parcs
- Réagissent aux passants

## Chats

Comportements :
- Se déplacent dans les ruelles
- Dorment sur les toits
- Explorent les quartiers

## Oiseaux

Espèces :

- Pigeons
- Mouettes
- Perroquets
- Aigles

Comportements :
- Volent au-dessus de la ville
- Se posent sur les bâtiments
- Réagissent au bruit

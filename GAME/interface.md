# GTA City IV - Interface du Jeu

## Écran principal

L'écran affiche :

- Barre de vie du joueur
- Argent disponible
- Carte mini-map
- Niveau de recherche
- Mission actuelle


## Carte GPS

Fonctions :

- Voir les 3 villes
- Marquer une destination
- Trouver les magasins
- Trouver les garages
- Voir les missions
- Localiser les véhicules rares


## Téléphone du joueur

Applications :

- Contacts
- Messages
- Carte
- Banque
- Missions
- Garage
- Véhicules


## Menu pause

Options :

- Continuer la partie
- Paramètres
- Graphismes
- Sons
- Véhicules
- Missions
- Sauvegarde


## Banque

Le joueur peut :

- Voir son argent
- Acheter des propriétés
- Gérer ses entreprises
- Payer des services


## Notifications

Le joueur reçoit :

- Nouveaux objectifs
- Appels importants
- Récompenses
- Événements de la ville

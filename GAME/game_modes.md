# GTA City IV - Modes de Jeu

## Mode Histoire

Le joueur suit l'aventure d'Alex Carter.

Contenu :
- Missions principales
- Missions secondaires
- Découverte des 3 villes
- Progression du personnage
- Déblocage de véhicules et propriétés


## Mode Libre Exploration

Le joueur peut :

- Explorer toute la carte
- Conduire tous les véhicules
- Découvrir des lieux secrets
- Acheter des maisons
- Modifier ses voitures
- Participer aux activités de la ville


## Mode Course

Types de courses :

- Courses de rue
- Courses de supercars
- Courses tout-terrain
- Courses de motos
- Courses aériennes
- Courses de bateaux


## Mode Défis

Défis disponibles :

- Défi de conduite
- Défi de vitesse
- Défi de pilotage
- Défi d'exploration


## Mode Multijoueur

Fonctions :

- Jouer avec ses amis
- Créer des équipes
- Faire des courses ensemble
- Explorer la ville en groupe
- Participer aux événements en ligne


## Mode Création

Le joueur peut créer :

- Son personnage
- Son style
- Ses véhicules
- Ses propriétés

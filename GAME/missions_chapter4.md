# GTA City IV - Chapitre 3 : La Guerre des Quartiers (Missions 46 à 75)

## Mission 46 - Le nouveau conflit

Objectif :
- Découvrir un conflit entre plusieurs quartiers
- Protéger ses alliés

Récompense :
- Réputation
- Nouveaux contacts


## Mission 47 - Le territoire perdu

Objectif :
- Reprendre un ancien quartier important

Récompense :
- Argent
- Accès à une nouvelle zone


## Mission 48 - Course interdite

Objectif :
- Participer à une course secrète dans Nova Santos

Récompense :
- Supercar rare


## Mission 49 - Le convoi

Objectif :
- Escorter un transport important

Récompense :
- Nouveau véhicule


## Mission 50 - Le piège

Objectif :
- Découvrir une trahison dans son entourage

Récompense :
- Informations secrètes


## Missions 51 à 60

Le joueur :
- Défend ses territoires
- Rencontre de nouveaux ennemis
- Débloque des entreprises
- Trouve des véhicules cachés
- Participe à de grandes courses


## Missions 61 à 70

Le joueur :
- Voyage entre les trois villes
- Découvre les secrets de Fort Shadow
- Affronte des groupes rivaux


## Missions 71 à 75

Le joueur :
- Prépare une grande opération
- Renforce son empire
- Se rapproche de Victor Kane


## Fin du chapitre 3

Récompenses :
- Nouveau quartier contrôlé
- Accès aux missions avancées
- Nouveaux véhicules
- Nouvelle réputation

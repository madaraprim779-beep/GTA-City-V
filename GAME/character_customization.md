# GTA City IV - Personnalisation du Personnage

## Création du personnage

Le joueur peut créer son propre personnage.

## Apparence

Options :

- Visage
- Coiffure
- Barbe
- Yeux
- Taille
- Style général


## Vêtements

Catégories :

- Tenue de rue
- Costume de luxe
- Tenue sportive
- Tenue de course
- Tenue de pilote
- Tenue spéciale de mission


## Accessoires

Le joueur peut ajouter :

- Lunettes
- Montres
- Casquettes
- Chaînes
- Sacs


## Styles disponibles

- Aventurier
- Homme d'affaires
- Pilote
- Sportif
- Style urbain


## Progression du personnage

Le joueur améliore :

- Réputation
- Compétences de conduite
- Compétences de pilotage
- Expérience des missions

# GTA City IV - Interface HUD et Menus

# 🎮 Interface en jeu

L'écran affiche les informations importantes :

- Mini-carte
- Position du joueur
- Objectif de mission
- Argent disponible
- Niveau de recherche
- Véhicule utilisé


# 🗺️ Mini-carte

Fonctions :

- Afficher les routes
- Montrer les missions
- Indiquer les commerces
- Afficher les propriétés
- Marquer les lieux importants


# 👤 Informations du joueur

Affichage :

- Santé
- Endurance
- Niveau
- Réputation
- Argent


# 🚗 Interface véhicule

Quand le joueur conduit :

- Vitesse
- Carburant
- État du véhicule
- GPS
- Radio active


# 📱 Téléphone du joueur

Le téléphone permet :

- Appels
- Messages
- Contacts
- Carte
- Missions
- Gestion des entreprises
- Photos


# 📋 Menu principal

Sections :

- Continuer la partie
- Nouvelle partie
- Multijoueur
- Paramètres
- Collection de véhicules
- Succès


# ⚙️ Paramètres

Options :

- Graphismes
- Audio
- Commandes
- Langue
- Connexion
- Sauvegarde


# 🎨 Personnalisation HUD

Le joueur peut modifier :

- Position des boutons
- Taille de la mini-carte
- Sensibilité des commandes
- Affichage des informations


# Objectif

Créer une interface claire et moderne adaptée au mobile, tout en gardant l'ambiance d'un grand jeu en monde ouvert.

# GTA City IV - Économie Avancée

# 💰 Argent du joueur

Le joueur gagne de l'argent grâce à :

- Missions principales
- Missions secondaires
- Courses
- Entreprises
- Récompenses
- Exploration
- Vente de véhicules
- Événements spéciaux

# 🏢 Entreprises

Le joueur peut acheter :

## Garage automobile
Revenus :
- Réparations
- Personnalisation
- Vente de véhicules

## Restaurant
Revenus :
- Clients
- Livraisons
- Événements privés

## Hôtel
Revenus :
- Réservations
- Suites VIP
- Services de luxe

## Concession automobile
Revenus :
- Vente de véhicules
- Commandes spéciales
- Modifications

## Marina
Revenus :
- Location de bateaux
- Entretien des yachts

## Compagnie aérienne privée
Revenus :
- Vols privés
- Transport VIP

# 📈 Investissements

Le joueur peut :

- Acheter des terrains
- Construire des bâtiments
- Agrandir ses entreprises
- Ouvrir de nouveaux commerces

# ⭐ Réputation

Une meilleure réputation permet de :

- Débloquer de nouvelles missions
- Accéder à des quartiers VIP
- Acheter des propriétés exclusives
- Rencontrer des personnages influents

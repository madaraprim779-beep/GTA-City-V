# GTA City IV - Système de Sauvegarde

## Sauvegarde de la partie

Le joueur peut sauvegarder sa progression dans :

- Villas
- Appartements
- Garages
- Points de sauvegarde


## Informations sauvegardées

Le jeu enregistre :

- Position du joueur
- Missions terminées
- Argent
- Véhicules possédés
- Propriétés achetées
- Entreprises du joueur
- Personnalisation du personnage
- Progression dans l'histoire


## Chargement

Au lancement du jeu :

- Charger une partie existante
- Commencer une nouvelle partie
- Choisir un profil


## Profils joueurs

Chaque profil contient :

- Nom du joueur
- Niveau
- Réputation
- Statistiques
- Collection de véhicules


## Sauvegarde automatique

Le jeu sauvegarde automatiquement après :

- Une mission terminée
- L'achat d'un véhicule
- L'achat d'une propriété
- Un événement important

# GTA City IV - Intelligence des PNJ

## Système d'intelligence

Les PNJ possèdent des comportements réalistes selon la situation.

## Comportement des habitants

Les habitants peuvent :

- Marcher dans les rues
- Aller au travail
- Visiter des commerces
- Utiliser les transports
- Changer de quartier
- Réagir aux événements


## Réactions des PNJ

Les PNJ peuvent :

- Observer un accident
- Appeler les secours
- Fuir une situation dangereuse
- Aider un personnage
- Réagir à la météo


## Circulation intelligente

Les véhicules :

- Respectent les feux
- Changent de direction
- Évitent les obstacles
- Créent des embouteillages
- Adaptent leur conduite selon la météo


## Police intelligente

La police :

- Analyse les situations
- Utilise différents véhicules
- Adapte les poursuites
- Augmente les recherches selon les actions du joueur


## Monde vivant

L'intelligence du monde gère :

- Les événements aléatoires
- Les activités des PNJ
- Les changements de quartiers
- Les réactions de la ville

# GTA City IV - Succès et Récompenses

## Succès principaux

### Première Légende
Objectif :
- Terminer les premières missions de l'histoire.

Récompense :
- Argent du jeu
- Nouveau véhicule


### Roi de la Ville
Objectif :
- Contrôler plusieurs quartiers.

Récompense :
- Nouvelle propriété
- Réputation augmentée


### Collectionneur Automobile
Objectif :
- Trouver plusieurs véhicules rares.

Récompense :
- Garage spécial


### Pilote Expert
Objectif :
- Gagner des courses terrestres et aériennes.

Récompense :
- Véhicule de compétition


## Défis cachés

- Découvrir toutes les zones secrètes
- Trouver les véhicules légendaires
- Explorer les îles
- Réussir les missions difficiles
- Acheter toutes les propriétés


## Récompenses spéciales

Le joueur peut obtenir :

- Véhicules uniques
- Tenues rares
- Argent du jeu
- Nouveaux lieux
- Missions secrètes

# GTA City IV - Système de Succès et Défis

# 🏆 Succès du joueur

Les succès récompensent les grandes actions réalisées dans le jeu.

---

# 🚗 Succès Véhicules

## Collectionneur Automobile

Objectif :
- Posséder plusieurs véhicules différents

Récompense :
- Garage spécial
- Véhicule rare


## Roi de la Route

Objectif :
- Gagner plusieurs courses

Récompense :
- Nouvelle voiture sportive


## Pilote Légendaire

Objectif :
- Maîtriser voitures, avions et bateaux

Récompense :
- Accès à des défis avancés

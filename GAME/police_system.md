# GTA City IV - Système de Police

# 🚔 Niveaux de Recherche

## ⭐ Niveau 1

Réponse :
- Une ou deux voitures de patrouille
- Contrôles simples

## ⭐⭐ Niveau 2

Réponse :
- Plusieurs patrouilles
- Barrages routiers dans certains quartiers

## ⭐⭐⭐ Niveau 3

Réponse :
- Unités d'intervention
- Hélicoptère de surveillance
- Recherche dans plusieurs zones

## ⭐⭐⭐⭐ Niveau 4

Réponse :
- Unités spéciales
- Véhicules blindés
- Hélicoptères supplémentaires
- Routes bloquées

## ⭐⭐⭐⭐⭐ Niveau 5

Réponse :
- Toutes les unités disponibles
- Barrages renforcés
- Véhicules rapides
- Surveillance aérienne continue

# 🚓 Types de véhicules

- Voiture de patrouille
- Moto de police
- SUV d'intervention
- Fourgon de transport
- Hélicoptère
- Véhicule blindé

# 👮 Comportement de la police

Les policiers peuvent :

- Patrouiller dans les rues
- Répondre aux appels d'urgence
- Poursuivre les suspects
- Sécuriser les zones importantes
- Contrôler la circulation après un accident

# 🚧 Barrages routiers

Selon le niveau de recherche :

- Contrôles de véhicules
- Routes fermées
- Vérification des ponts
- Surveillance des tunnels
- Contrôle des aéroports et des ports

# 🚨 Centre de commandement

Le centre de commandement coordonne :

- Les patrouilles
- Les interventions
- Les poursuites
- Les secours

# 🏆 Récompenses

Si le joueur échappe à une poursuite :

- Réputation augmentée
- Défi terminé
- Succès débloqués

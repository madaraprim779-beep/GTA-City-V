# GTA City IV - Commandes Mobile

# 📱 Contrôles tactiles

Le jeu est conçu pour être jouable sur smartphone.

---

# 🎮 Déplacement du personnage

## Joystick gauche

Fonctions :

- Marcher
- Courir
- Changer de direction
- Se déplacer dans les bâtiments

---

# 👆 Actions principales

Boutons à l'écran :

- Interagir
- Sauter
- Monter dans un véhicule
- Descendre d'un véhicule
- Sprinter
- Accéder au téléphone

---

# 🚗 Conduite des véhicules

Modes disponibles :

## Mode classique

- Volant virtuel
- Accélérateur
- Frein
- Marche arrière

## Mode boutons

- Tourner à gauche
- Tourner à droite
- Accélérer
- Freiner

---

# ✈️ Pilotage

Avions et hélicoptères :

- Contrôle de direction
- Altitude
- Caméra libre
- Atterrissage assisté

---

# 🎯 Interaction avec le monde

Le joueur peut :

- Ouvrir des portes
- Utiliser des magasins
- Entrer dans les bâtiments
- Interagir avec les PNJ

---

# ⚙️ Personnalisation des commandes

Le joueur peut modifier :

- Taille des boutons
- Position des boutons
- Sensibilité
- Type de conduite
- Inversion des commandes

---

# 🎮 Support manette

Compatible avec :

- Manettes Bluetooth
- Contrôleurs mobiles
- Claviers compatibles

---

# Objectif

Créer des commandes simples, précises et confortables pour jouer à GTA City IV sur téléphone.

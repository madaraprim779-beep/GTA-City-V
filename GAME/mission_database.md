# GTA City IV - Base de Données des Missions

## Chapitre 1 : Le Retour à Nova Santos

### Mission 1 - Nouveau départ

Objectif :
- Arriver dans la ville
- Trouver un endroit où dormir
- Découvrir les premiers quartiers

Récompense :
- Argent
- Carte de la ville


### Mission 2 - Anciennes connaissances

Objectif :
- Retrouver Marcus Reed
- Obtenir un premier véhicule

Récompense :
- Nouveau contact
- Garage débloqué


### Mission 3 - Premier contrat

Objectif :
- Réaliser une mission pour un habitant important

Récompense :
- Argent
- Réputation


### Mission 4 - Course de nuit

Objectif :
- Participer à une course automobile

Récompense :
- Voiture sportive


### Mission 5 - Le garage abandonné

Objectif :
- Explorer un ancien garage
- Découvrir un secret

Récompense :
- Véhicule rare


## Progression

Le jeu contient :

- 120 missions principales
- Plus de 200 missions secondaires
- Missions de personnages
- Missions secrètes
- Événements aléatoires

Chaque mission possède :
- Une histoire
- Des objectifs
- Des récompenses
- Des lieux uniques

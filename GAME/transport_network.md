# GTA City IV - Réseau de Transport

## Routes

Le monde possède un grand réseau routier :

- Autoroutes entre les 3 villes
- Routes de campagne
- Routes de montagne
- Routes du désert
- Ponts géants


## Transports publics

### Bus

Fonctions :
- Transport des habitants
- Plusieurs lignes dans les villes
- Arrêts dans les quartiers importants


### Taxi

Fonctions :
- Déplacement rapide
- Transport de personnages
- Missions de chauffeur


### Métro

Ville :
- Nova Santos

Fonctions :
- Déplacement sous la ville
- Plusieurs stations
- Transport rapide


## Transports privés

Le joueur peut utiliser :

- Voitures
- Motos
- Avions
- Hélicoptères
- Bateaux


## Voyage entre les villes

Moyens :

- Autoroute
- Train
- Avion
- Bateau


## Stations importantes

- Gare centrale
- Aéroports
- Ports
- Stations-service
- Aires de repos


## Objectif

Créer un monde ouvert où le joueur peut se déplacer librement dans toute la carte.

# GTA City IV - Optimisation Mobile

## Objectif

Créer un jeu avec de beaux graphismes tout en gardant de bonnes performances sur téléphone.

## Modes graphiques

### Mode Économie
- Textures réduites
- Moins de détails
- Meilleure fluidité

### Mode Normal
- Graphismes équilibrés
- Ville détaillée
- Bonne performance

### Mode Élevé
- Meilleures textures
- Reflets améliorés
- Plus de détails

### Mode Ultra
- Qualité maximale
- Effets réalistes
- Réservé aux téléphones puissants


## Optimisation du monde

- Chargement intelligent des zones
- Réduction des objets éloignés
- Compression des fichiers
- Gestion de la mémoire


## Contrôles mobiles

Le jeu possède :

- Joystick virtuel
- Boutons d'action
- Carte tactile
- Interface adaptée téléphone


## Sauvegarde

- Sauvegarde locale
- Sauvegarde en ligne
- Synchronisation du profil


## Objectif final

Obtenir un monde ouvert réaliste avec :
- Grande carte
- PNJ vivants
- Véhicules détaillés
- Missions nombreuses
- Bonne fluidité sur mobile

# GTA City IV - Activités et Loisirs

# 🎮 Activités Secondaires

En dehors des missions principales, le joueur peut profiter de nombreuses activités.

---

# 🏀 Sports

Activités disponibles :

- Basketball
- Football
- Tennis
- Golf
- Billard
- Bowling

Récompenses :

- Argent
- Réputation
- Succès

---

# 🏋️ Salle de sport

Le joueur peut :

- S'entraîner
- Participer à des défis
- Améliorer son endurance
- Débloquer de nouvelles animations

---

# 🎯 Mini-jeux

Le monde contient :

- Fléchettes
- Arcade
- Jeux de course
- Défis de précision
- Jeux d'adresse

---

# 🎡 Événements de la ville

Selon la période :

- Festivals
- Concerts
- Feux d'artifice
- Salons automobiles
- Expositions

---

# 🏖️ Loisirs

Le joueur peut :

- Se promener sur la plage
- Faire du bateau
- Pêcher
- Camper
- Explorer les montagnes

---

# 📸 Exploration

Activités :

- Photographier les paysages
- Découvrir des lieux cachés
- Trouver des objets de collection
- Visiter les monuments

---

# 🏆 Défis Quotidiens

Chaque jour, de nouveaux défis apparaissent :

- Parcourir une distance
- Gagner une course
- Explorer un quartier
- Réaliser des figures en véhicule
- Terminer une activité spéciale

Récompenses :

- Argent
- Expérience
- Objets exclusifs
- Bonus de réputation

---

# 🌍 Objectif

Créer un monde où le joueur peut s'amuser même sans suivre l'histoire principale, avec des activités variées dans les trois villes.

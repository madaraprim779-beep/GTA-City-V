# GTA City IV - Système de Circulation

# 🚦 Circulation Intelligente

La circulation évolue selon :

- L'heure de la journée
- La météo
- Les événements
- Les quartiers

---

# 🚗 Types de véhicules

Les routes accueillent :

- Voitures citadines
- Berlines
- SUV
- Supercars
- Camions
- Bus
- Taxis
- Motos
- Véhicules de livraison

---

# 🚥 Feux de circulation

Les conducteurs :

- Respectent les feux rouges
- S'arrêtent aux passages piétons
- Cèdent le passage
- Utilisent les clignotants

---

# 🚧 Embouteillages

Des bouchons peuvent apparaître à cause de :

- Heures de pointe
- Accidents
- Travaux routiers
- Événements en ville

---

# 🚑 Réaction aux urgences

Quand une ambulance, un camion de pompiers ou une voiture de police arrive :

- Les véhicules se rangent
- Les conducteurs ralentissent
- Les intersections se dégagent

---

# 🅿️ Stationnement

Les véhicules peuvent :

- Se garer sur des places prévues
- Entrer dans des parkings
- Quitter leur stationnement automatiquement

---

# 🌧️ Influence de la météo

La circulation change selon les conditions :

- Pluie : vitesse réduite
- Brouillard : prudence accrue
- Orage : trafic plus lent
- Tempête de sable : routes parfois fermées

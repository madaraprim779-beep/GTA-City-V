# GTA City IV - Factions

## Empire Kane

Description :
Le groupe le plus puissant de GTA City IV. Il contrôle plusieurs quartiers et possède des entreprises cachées.

Zones d'influence :
- Nova Santos
- Silver Vegas

Activités :
- Contrôle de territoires
- Affaires secrètes
- Conflits avec le joueur


## Street Kings

Description :
Un groupe de pilotes et de passionnés de voitures.

Zones :
- Quartiers urbains
- Circuits de course

Activités :
- Courses de rue
- Tuning
- Défis automobiles


## Ocean Wolves

Description :
Un groupe lié au port et aux activités maritimes.

Zones :
- Bay City
- Marina
- Port industriel

Activités :
- Transport maritime
- Courses de bateaux
- Missions du port


## Force de Police

Description :
Les forces de l'ordre protègent la ville.

Rôles :
- Patrouilles
- Enquêtes
- Poursuites


## Forces Militaires

Description :
Une organisation basée à Fort Shadow.

Rôles :
- Protection de la base
- Missions spéciales
- Sécurité des zones sensibles


## Alliés du joueur

Le joueur peut créer son propre groupe :

- Recruter des membres
- Posséder des quartiers
- Gérer des activités
- Construire son empire

# GTA City IV - Radios et Musiques

## Système de radio

Chaque véhicule possède une radio avec plusieurs stations.

Le joueur peut changer de station pendant ses déplacements.

---

## City Beats FM

Style :
- Rap
- Hip-hop
- Musique urbaine

Ville principale :
- Nova Santos

Contenu :
- Nouveaux artistes
- Interviews
- Actualités de la ville


## Night Pulse Radio

Style :
- Électro
- Phonk
- Musique de nuit

Ville principale :
- Bay City

Contenu :
- Ambiance des clubs
- Événements nocturnes


## Desert Rock Radio

Style :
- Rock
- Musique d'aventure

Ville principale :
- Silver Vegas

Contenu :
- Voyages dans le désert
- Émissions spéciales


## Speed Race FM

Style :
- Musiques de course
- Sons rapides

Utilisation :
- Courses automobiles
- Événements sportifs


## News City Radio

Contenu :
- Informations sur la ville
- Météo
- Alertes importantes
- Événements en cours


## Fonctionnalités

- Radios différentes selon les quartiers
- Publicités fictives
- Animateurs
- Nouvelles chansons ajoutées avec les mises à jour
- Musiques spéciales pour les missions

# GTA City IV - Vie Quotidienne des PNJ

# 👥 Habitants de la ville

Les PNJ ont des routines différentes pour rendre la ville réaliste.

---

# 🌅 Matin

Les habitants peuvent :

- Aller au travail
- Prendre le bus ou le métro
- Acheter un café
- Ouvrir les commerces
- Aller à l'école

---

# ☀️ Journée

Activités :

- Travailler dans les entreprises
- Faire des achats
- Visiter les restaurants
- Se promener dans les parcs
- Utiliser les transports

---

# 🌙 Soirée

La ville change :

- Les restaurants deviennent plus actifs
- Les clubs ouvrent
- Les quartiers deviennent plus animés
- Les événements apparaissent

---

# 🌃 Nuit

Les PNJ peuvent :

- Rentrer chez eux
- Sortir dans les lieux de divertissement
- Participer à des événements nocturnes

---

# 🏢 Métiers des PNJ

Les habitants peuvent être :

- Chauffeurs de taxi
- Mécaniciens
- Commerçants
- Policiers
- Médecins
- Pompiers
- Employés de bureau
- Travailleurs du port

---

# 🗣️ Interactions

Le joueur peut :

- Parler avec certains PNJ
- Recevoir des informations
- Découvrir des missions
- Créer des relations

---

# 🌍 Monde dynamique

Les PNJ réagissent à :

- La météo
- L'heure
- Les événements
- Les actions du joueur
- Les changements dans la ville

# GTA City IV - Système de Missions

# 🎯 Types de missions

## Missions principales

Fonctions :
- Faire avancer l'histoire
- Débloquer de nouvelles zones
- Rencontrer des personnages importants

Récompenses :
- Argent
- Réputation
- Véhicules
- Propriétés


## Missions secondaires

Types :

- Courses
- Livraisons
- Exploration
- Défis de conduite
- Aide aux habitants


## Missions secrètes

Disponibles grâce à :

- Exploration de la carte
- Indices cachés
- Personnages spéciaux
- Lieux secrets


# 📍 Objectifs de mission

Une mission peut demander :

- Aller à un endroit précis
- Transporter un objet
- Participer à une course
- Explorer une zone
- Rencontrer un personnage
- Terminer un défi


# 🗺️ Marqueurs de carte

La carte affiche :

- Missions disponibles
- Objectifs actuels
- Personnages importants
- Récompenses
- Lieux à découvrir


# ⭐ Difficulté

Niveaux :

Facile :
- Missions d'apprentissage

Moyen :
- Missions avec plusieurs objectifs

Difficile :
- Missions longues
- Grandes récompenses


# 🏆 Récompenses

Après une mission :

- Argent du jeu
- Expérience
- Réputation
- Nouveaux contacts
- Déblocage de contenu


# 📊 Progression

Le système suit :

- Missions terminées
- Pourcentage d'histoire
- Défis réussis
- Secrets découverts
- Récompenses obtenues

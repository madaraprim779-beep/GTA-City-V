# GTA City IV - Téléphone du Joueur

## Smartphone

Le joueur possède un téléphone moderne avec plusieurs applications.

## Applications principales

### Contacts

Fonctions :
- Appeler les personnages
- Recevoir des missions
- Obtenir des informations


### Messages

Fonctions :
- Recevoir des objectifs
- Lire les notifications
- Communiquer avec les alliés


### Carte GPS

Fonctions :
- Voir la carte complète
- Placer des marqueurs
- Trouver des lieux importants
- Localiser les véhicules


### Banque

Fonctions :
- Voir son argent
- Gérer ses achats
- Payer certains services


### Garage

Fonctions :
- Voir ses véhicules
- Choisir un véhicule
- Gérer ses améliorations


### Appareil photo

Fonctions :
- Prendre des photos
- Découvrir des secrets
- Compléter certains défis


## Appels importants

Le joueur reçoit des appels pour :

- Missions principales
- Missions secondaires
- Alertes de la ville
- Nouveaux événements


## Personnalisation

Le joueur peut modifier :

- Fond d'écran
- Sonnerie
- Apparence du téléphone
- Applications disponibles

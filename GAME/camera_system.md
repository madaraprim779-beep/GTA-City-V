# GTA City IV - Système de Caméra

# 🎥 Vue du joueur

Le jeu propose plusieurs vues :

## Vue troisième personne

Fonctions :
- Caméra derrière le personnage
- Vision complète de l'environnement
- Adaptation automatique aux obstacles


## Vue première personne

Fonctions :
- Vision depuis les yeux du personnage
- Immersion dans les véhicules
- Exploration détaillée des bâtiments


# 🚗 Caméra des véhicules

La caméra s'adapte selon le véhicule :

## Voitures

- Vue arrière
- Vue intérieure
- Vue capot


## Motos

- Vue dynamique
- Effets de vitesse
- Inclinaison dans les virages


## Avions et hélicoptères

- Vue cockpit
- Vue extérieure
- Caméra libre


# 🎬 Caméra cinématique

Utilisée pour :

- Missions importantes
- Arrivées de véhicules
- Scènes d'histoire
- Moments spéciaux


# 🌆 Caméra intelligente

Le système :

- Évite les murs
- Suit le joueur automatiquement
- Ajuste la distance selon la situation
- Change d'angle pendant les actions importantes


# ⚙️ Réglages

Le joueur peut modifier :

- Sensibilité caméra
- Distance
- Inversion verticale
- Mode automatique ou manuel


# Objectif

Créer une caméra fluide qui donne une sensation de grand jeu en monde ouvert.

# GTA City IV - Système de Logement du Joueur

# 🏠 Acheter une propriété

Le joueur peut acheter différents types de logements :

## Petit appartement

Ville :
- Nova Santos

Fonctions :
- Point de sauvegarde
- Changement de vêtements
- Stockage limité


## Maison familiale

Fonctions :
- Plus d'espace
- Garage simple
- Décoration intérieure


## Villa de luxe

Fonctions :
- Grande propriété
- Piscine
- Garage pour plusieurs véhicules
- Salle privée


## Propriété spéciale

Exemples :
- Villa sur une île
- Penthouse en centre-ville
- Domaine dans les collines


# 🎨 Personnalisation du logement

Le joueur peut modifier :

- Meubles
- Décoration
- Couleurs des pièces
- Éclairage
- Style intérieur


# 🚗 Garages personnels

Types :

## Garage classique
- 2 à 5 véhicules

## Garage sportif
- Voitures de course
- Supercars

## Garage collection
- Véhicules rares
- Véhicules légendaires


# 🏢 Amélioration des propriétés

Le joueur peut ajouter :

- Salle de sport
- Bureau
- Salle de jeux
- Atelier de tuning
- Héliport privé


# 🔐 Propriétés secrètes

Certaines maisons cachées possèdent :

- Entrées secrètes
- Salles cachées
- Véhicules rares
- Missions spéciales


# Objectif

Créer un système où chaque propriété devient un élément important de la progression du joueur.
